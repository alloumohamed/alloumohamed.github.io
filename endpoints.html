git/trees API → live route map

Endpoint Explorer

Enter any GitHub Pages repo (user/user.github.io) and this pulls the file tree straight from GitHub's API, then generates the resulting site routes automatically — HTML files become clean endpoints, folders become groups.
Calls api.github.com/repos/<owner>/<repo>/git/trees/<branch>?recursive=1 directly from your browser — no server, no key. Unauthenticated GitHub API calls are capped at 60/hour per IP.
